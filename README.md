# 🧭 Directory App  
A modern, responsive, and user-friendly **Directory Web Application** built with React.js.  
Easily **browse**, **search**, and **manage** directory entries — perfect for showcasing businesses, services, or contacts in a clean interface.

----

## 👉 **Live Demo:** [Directory App](https://directory-app-blush.vercel.app/)

----

## ✨ Features 

📇 **Add New Entries** — Quickly add people or businesses to the directory.  
🔍 **Search Functionality** — Instantly filter and find entries by name or Aadhaar number.  
📝 **Real-time Data Display** — All records are shown neatly in a structured format.  
💾 **Local Storage Integration** — Your data stays even after page refresh.  
📱 **Responsive Design** — Works smoothly on mobile, tablet, and desktop.  
🔐 **Unique Aadhaar-based Identification** — Avoids duplicate entries.  
♻️ **Delete / Clear Options** — Remove individual entries or clear all with one click. 

---

## 🚀 Tech Stack 

- **Frontend:** React.js, JavaScript, HTML, CSS  
- **Styling:** Custom CSS  
- **Deployment:** Vercel  
- **Storage:** Local Storage

## 🎮 How to Use

- Enter a name and Aadhaar number in the input fields.
- Click Add to save the entry to the directory.
- Use the Search bar to quickly find people.
- Click Delete to remove an entry or Clear All to reset the list.
- Data persists in local storage — no backend required!
